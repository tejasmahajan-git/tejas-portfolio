# Tejas Mahajan — Free Portfolio Website

This is a responsive static portfolio built with plain HTML and CSS. No paid hosting, framework, database, or build step is required.

## Preview
Open `index.html` in your browser.

## Publish for free with GitHub Pages
1. Create a **public** GitHub repository named `tejasmahajan-git.github.io` (if your username is exactly `tejasmahajan-git`).
2. Upload `index.html` to the repository root and commit.
3. Go to **Settings → Pages**.
4. Under build/deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. After publishing, the site will be available at `https://tejasmahajan-git.github.io/`.
